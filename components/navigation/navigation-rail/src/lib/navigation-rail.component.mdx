## Getting Started

### 1. Import the module

<Source
  language="ts"
  code={`import { MAT_NAVIGATION_RAIL_MODULES } from '@fairylights-studio/navigation-rail';
import { MatIconModule } from '@angular/material/icon';

### 2. TypeScript — component class

<Source
  language="ts"
  code={`import { Component } from '@angular/core';
import { MAT_NAVIGATION_RAIL_MODULES } from '@fairylights-studio/navigation-rail';
import { MatIconModule } from '@angular/material/icon';
import { MatButtonModule } from '@angular/material/button';

@Component({
selector: 'app-my-page',

})
export class MyPageComponent {
selectedIndex = 0;
expanded = false;
}`}
/>

## Content Projection Directives

These structural directives control what gets projected into each `mat-navigation-rail-item`.

| Directive                  | Selector                    | Purpose                               |
| -------------------------- | --------------------------- | ------------------------------------- |
| `*matNavigationIcon`       | `[MatNavigationIcon]`       | Primary icon displayed in the item.   |
| `*matNavigationActiveIcon` | `[MatNavigationActiveIcon]` | Alternative icon shown when `active`. |
| `matNavigationLabel`       | `[MatNavigationLabel]`      | Label text for the item.              |
