## Getting Started

### 1. Import the module

<Source
  language="ts"
  code={`import { MAT_NAVIGATION_BAR_MODULES } from '@fairylights-studio/navigation-bar';
import { MatIconModule } from '@angular/material/icon';
import { MatBadgeModule } from '@angular/material/badge';`}

### 2. TypeScript — component class

<Source
  language="ts"
  code={`import { Component } from '@angular/core';
import { MAT_NAVIGATION_BAR_MODULES } from '@fairylights-studio/navigation-bar';
import { MatIconModule } from '@angular/material/icon';
import { MatBadgeModule } from '@angular/material/badge';

selector: 'app-my-page',

}`}
/>

## Content Projection Directives

These structural directives control what gets projected into each `mat-navigation-bar-item`.

| Directive                  | Selector                    | Purpose                               |
| -------------------------- | --------------------------- | ------------------------------------- |
| `*matNavigationIcon`       | `[MatNavigationIcon]`       | Primary icon displayed in the item.   |
| `*matNavigationActiveIcon` | `[MatNavigationActiveIcon]` | Alternative icon shown when `active`. |
| `matNavigationLabel`       | `[MatNavigationLabel]`      | Label text for the item.              |
