## Getting Started

### 1. Configure Angular Material

Configure Angular Material in your application styles. Navigation bar consumes the generated `--mat-sys-*` runtime variables and does not provide a Sass theme mixin.

### 2. Import the module

<Source
  language="ts"
  code={`import { MAT_NAVIGATION_BAR_MODULES } from '@fairylights-studio/navigation-bar';
import { MatIconModule } from '@angular/material/icon';
import { MatBadgeModule } from '@angular/material/badge';`}
/>

### 3. TypeScript — component class

<Source
  language="ts"
  code={`import { Component } from '@angular/core';
import { MAT_NAVIGATION_BAR_MODULES } from '@fairylights-studio/navigation-bar';
import { MatIconModule } from '@angular/material/icon';
import { MatBadgeModule } from '@angular/material/badge';

@Component({
selector: 'app-my-page',
imports: [MAT_NAVIGATION_BAR_MODULES, MatIconModule, MatBadgeModule],
templateUrl: './my-page.component.html',
styleUrl: './my-page.component.scss',
})
export class MyPageComponent {
selectedIndex = 0;
}`}
/>

## Runtime CSS Variables

`--flight-*` variables are public customization hooks owned by this library. Color, typography, and motion come from Angular Material `--mat-sys-*` variables.

| CSS variable | Default | Used for | Override example |
| --- | --- | --- | --- |
| `--flight-nav-bar-container-height` | `80px` | Vertical bottom bar height | `.shell { --flight-nav-bar-container-height: 84px; }` |
| `--flight-nav-bar-container-horizontal-height` | `64px` | Horizontal bar height | `.shell { --flight-nav-bar-container-horizontal-height: 72px; }` |
| `--flight-nav-bar-item-container-z-index` | `100` | Bar host stacking | `.shell { --flight-nav-bar-item-container-z-index: 10; }` |
| `--flight-nav-bar-item-min-width` | `88px` | Vertical item minimum width | `.shell { --flight-nav-bar-item-min-width: 96px; }` |
| `--flight-nav-bar-item-horizontal-width` | `168px` | Horizontal item width | `.shell { --flight-nav-bar-item-horizontal-width: 184px; }` |
| `--flight-nav-bar-item-horizontal-height` | `64px` | Horizontal item height | `.shell { --flight-nav-bar-item-horizontal-height: 72px; }` |
| `--flight-nav-bar-item-icon-wrapper-width` | `56px` | Vertical indicator width | `.shell { --flight-nav-bar-item-icon-wrapper-width: 64px; }` |
| `--flight-nav-bar-item-icon-wrapper-height` | `32px` | Vertical indicator height | `.shell { --flight-nav-bar-item-icon-wrapper-height: 36px; }` |

| `--flight-nav-bar-item-horizontal-indicator-shape` | `20px` | Horizontal indicator radius | `.shell { --flight-nav-bar-item-horizontal-indicator-shape: 22px; }` |
| `--flight-nav-bar-item-horizontal-padding` | `0 20px` | Horizontal item indicator padding | `.shell { --flight-nav-bar-item-horizontal-padding: 0 24px; }` |

## Content Projection Directives

These structural directives control what gets projected into each `mat-navigation-bar-item`.

| Directive                  | Selector                    | Purpose                               |
| -------------------------- | --------------------------- | ------------------------------------- |
| `*matNavigationIcon`       | `[MatNavigationIcon]`       | Primary icon displayed in the item.   |
| `*matNavigationActiveIcon` | `[MatNavigationActiveIcon]` | Alternative icon shown when `active`. |
| `matNavigationLabel`       | `[MatNavigationLabel]`      | Label text for the item.              |
