Third-party Material 3 component extensions for Angular Material.

## Components

### Navigation

- **Navigation Bar** - Bottom navigation for compact layouts.
- **Navigation Rail** - Side navigation rail with Expressive expanded and collapsed states.
- **Navigation Suite** - Responsive scaffold that switches between navigation bar and navigation rail layouts.

### Button

- **Extended FAB Collapsed** - Collapsed state support for Angular Material extended FABs.

## Package Scope

These packages are designed to work with Angular Material and consume Angular Material system tokens such as `--mat-sys-*`.

They are third-party implementations by FairyLights Studio, not official Angular or Google components.
